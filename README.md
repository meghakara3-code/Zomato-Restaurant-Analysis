Zomato Restaurant Analysis
Project Overview
This project analyzes Zomato restaurant data to understand restaurant ratings, pricing, customer preferences, and restaurant trends.

Project Objectives
Analyze restaurant ratings and customer reviews.
Explore restaurant pricing and cuisines.
Understand restaurant trends and customer preferences.
Generate meaningful business insights from the data.

Tools Used
Microsoft Excel
Data Analysis and Visualization

Project Files
Dataset: Zomato restaurant data in Excel format.
Documentation: Project details and analysis.
Presentation: Project findings and insights.

Key Insights
Key findings and business recommendations are documented in the project report and presentation.

Conclusion
This project helps understand restaurant performance and customer preferences through data analysis.
